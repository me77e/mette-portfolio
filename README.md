# Mette Holmström – portfolio

Neljä HTML-sivua, yhteinen CSS ja linkkien asetustiedosto. Sisältö on toteutettu toimitettujen suunnitelmakuvien mukaan. Kaikki teksti käyttää Geologica-fonttia; fonttitiedostot sisältyvät projektiin.

## Käyttö VS Codessa

1. Pura ZIP ja avaa koko kansio VS Codessa.
2. Avaa index.html selaimessa tai VS Coden Live Serverillä.
3. Muokkaa sivujen sisältöä HTML-tiedostoista ja tyylejä css/styles.css-tiedostosta.

## Puuttuvat linkit

Lisää projektisivuston, Figma-prototyypin, LinkedIn-profiilin ja CV:n oikeat osoitteet js/script.js-tiedoston portfolioLinks-objektiin. Tyhjät linkit näkyvät suunnitelman mukaisella tekstillä, mutta eivät avaa mitään. Sähköpostilinkki toimii valmiiksi.

## Kuvat

images/omakuva.jpg, images/referenssi1.png ja images/referenssi2.png on rajattu toimitetuista suunnitelmakuvista. Korvaa ne alkuperäisillä kuvilla samoilla tiedostonimillä, jos haluat tarkemmat kuvat.

## Värit

- Tausta: #9B9182 (suunnitelmakuvasta)
- Isot otsikot: #FAF7F2
- Alaotsikot ja navigaatio: #243F35
- Tekstit: #252525

Sivut mukautuvat puhelimeen, tablettiin ja tietokoneeseen. Julkaisu GitHub Pagesissa onnistuu ilman erillistä build-komentoa, kun nämä tiedostot ovat repositorion juuressa.

## Koko selainikkunan asettelu

Tausta täyttää selainikkunan leveyden ja vähintään sen korkeuden. Sisältö ja kuvat mukautuvat näytön kokoon. Sisältö saa tarvittaessa vierittyä, jotta mitään ei leikkaannu pois.
